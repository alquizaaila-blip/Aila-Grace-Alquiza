PORTFOLIO SECTION REPLACEMENT

This is a self-contained replacement for the Portfolio section.
It includes four visual project images as inline SVG graphics, so you do NOT need to upload separate image files.

To use it in your existing GitHub portfolio:
1. Open index.html.
2. Find the old Portfolio section.
3. Replace that section with the <section class="portfolio"...> section from this file.
4. Also copy the modal and script near the bottom of this file before </body>.
5. Commit the changes.

The four cards are:
- Vacant Land Research
- Comparative Market Analysis
- CRM Data Organization
- Skip Tracing & Lead Lists

The cards are responsive and clickable, with a project preview popup.
