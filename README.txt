GITHUB PAGES
------------
1. Upload every file in this folder to the root of your GitHub repository.
2. Make sure index.html, styles.css, script.js and hero-photo.png are in the same folder.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.

RESUME
------
The Download Resume button expects a file named resume.pdf in the same folder.
Add your actual resume PDF to the repository if you want that button to work.
