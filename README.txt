## GitHub
Upload all files into the same repository root. Keep `hero-photo.png` in the same folder as `index.html`.

For the resume button, upload your actual resume as:
`resume.pdf`

Then enable GitHub Pages:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

No framework or build process is required.
