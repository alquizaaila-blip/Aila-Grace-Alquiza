## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

Example:
- VS Code + Live Server
- `python -m http.server`

## Notes

- The supplied profile photo is used in the hero.
- The four portfolio visuals were cropped from the supplied portfolio reference screenshot so the project can run immediately.
- The Tools section recreates the complete 30-item grid using lightweight logo/text placeholders, matching the visual treatment of the reference.
- The contact form uses a `mailto:` action and therefore needs no backend.
- To make the resume button download a real file, add `assets/Aila-Grace-Alquiza-Resume.pdf` and point the button to it.
